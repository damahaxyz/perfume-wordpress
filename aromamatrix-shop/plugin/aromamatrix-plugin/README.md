# AROMAMATRIX Plugin

Site-specific WordPress plugin for AROMAMATRIX business functionality.

The plugin currently manages the protected WooCommerce factory-model field used
for supplier communication. Administrators can edit the value on the product
screen, see it beside the SKU in the Products list, and find products with the
standard Products search box. The field remains hidden from customers.

Add future features such as inquiry workflows, integrations, APIs, and scheduled
jobs here so they continue working when the theme changes.
